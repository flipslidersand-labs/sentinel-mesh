# ADR-001: eBPF Agent を Rust + Aya で実装する

- 日付: 2026-06-24
- ステータス: 承認済み

## 背景

分散観測のエージェント部分はカーネルイベントを高頻度で取得するため、
オーバーヘッドが極めて小さい言語とフレームワークが必要。

## 決定

Rust + Aya を採用する。eBPF プログラムとユーザースペース収集器を
同一言語で書き、unsafe を最小限に抑える。

## 理由

- Aya は Rust ネイティブの eBPF フレームワークで libbpf 依存なし
- カーネル側バイナリとユーザースペース側が同一 workspace で管理可能
- メモリ安全性により ring_buf 処理のバグを静的に排除できる

## トレードオフ

- eBPF の Rust ツールチェーンセットアップが複雑（bpf-linker 必須）
- C の libbpf ベースより事例が少ない
